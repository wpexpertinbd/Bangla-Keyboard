This app is FREE, open-source and safe -- but it is NOT signed by Apple
(that requires a paid Apple Developer account). So the FIRST time you open
it, macOS shows a security warning. This is normal. Here is exactly what
to do.


------------------------------------------------------------
HOW TO INSTALL  (English)
------------------------------------------------------------

1. Double-click  "Bangla Keyboard Installer".

2. macOS shows:  "Bangla Keyboard Installer" Not Opened --
   "Apple could not verify ...".   Click  Done.

3. Open the  Apple menu  ->  System Settings  ->  Privacy & Security.

4. Scroll down to the  "Security"  section. You will see:

        "Bangla Keyboard Installer" was blocked ...   [ Open Anyway ]

   Click  Open Anyway.

5. On the confirmation, click  Open Anyway  again, then unlock with your
   Touch ID  or  password.

6. The installer opens  ->  click  Install  ->  enter your password.

7. IMPORTANT:  Log out and log back in  (or restart your Mac).
   macOS only loads new keyboard layouts after a fresh login.

8. System Settings -> Keyboard -> Text Input -> Edit... -> "+" -> Bangla
   ->  add  "Bangla Unicode", "Bangla Classic"  and/or  "Bangla Phonetic".

9. Switch keyboards with the menu-bar flag icon, or press  Control + Space.

To uninstall later:  open this app again -> choose  Uninstall.

TIP: You can also use "Bangla Keyboard.pkg" from the GitHub Releases page.
It is unsigned too: double-click it -> Done -> System Settings ->
Privacy & Security -> Open Anyway  (same steps as above).

------------------------------------------------------------
VOICE TYPING (optional)  -  "Bangla Voice"
------------------------------------------------------------
This disk image also contains  "Bangla Voice"  -  speak, and it types
what you said into any app. The keyboard works fine without it.

REQUIRES AN APPLE SILICON MAC (M1 or newer). On an Intel Mac the keyboard
works normally, but this voice app will not open.

1. Drag  "Bangla Voice"  into your  Applications  folder, then open it.
   The first time macOS blocks it the same way as above:  Done  ->
   System Settings -> Privacy & Security -> Open Anyway.

2. It lives in the MENU BAR (a flag icon), not in the Dock.

3. Allow  Microphone  when asked. Then, from its menu-bar icon, choose
   "Grant Accessibility..."  so it can type into other apps.

4. Control + Option + S  =  speak Bangla
   Control + Option + D  =  speak English
   Press the same keys again to stop listening.

5. Speak the punctuation out loud:
       দাঁড়ি -> ।     কমা -> ,     প্রশ্ন -> ?     বিস্ময় -> !

PRIVACY: English is recognised ON YOUR MAC (nothing is sent anywhere).
Bangla audio is sent to Google's free speech service to be recognised,
only while you are holding a voice mode on. Nothing is ever recorded
or stored.

TYPING - Bangla Phonetic  (type it the way it sounds)
------------------------------------------------------------
Bangla appears AS YOU TYPE.  Examples:
   ami -> আমি      tumi -> তুমি      kemon -> কেমন     bangla -> বাংলা
   O  = ো :  bhalO -> ভালো    (a plain o after a consonant is silent: keno -> কেন)
   c = চ   ch = ছ      s = স   sh / S = শ   Sh = ষ
   t/T = ত/ট   d/D = দ/ড   n/N = ন/ণ   r/R = র/ড়   rri = ঋ / ৃ  (krriShok -> কৃষক)
   Conjuncts form by themselves:  golpo -> গল্প   okkhor -> অক্ষর
   rr = reph  (korrmo -> কর্ম)    y = য-ফলা (bybohar)    w = ব-ফলা (bishwo)
   .  = ।     ,, = হসন্ত     ^ = ঁ     : = ঃ     $ = ৳
   `  (the key left of 1) keeps two letters apart:  jan`te -> জানতে


------------------------------------------------------------
TYPING TIP - Bangla Classic (ও-কার / এ-কার)
------------------------------------------------------------
Type the consonant FIRST, then the vowel sign - NO space:
   স then ে        -> সে
   স then ে then া -> সো
   ত then ে then া -> তো
This keeps Space as a clean word-gap, so words no longer stick
together.  (Older builds used Space to make these - just drop it.)
